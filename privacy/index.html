tasks-vizzy — Privacy Policy

Last updated: 13 September 2026

tasks-vizzy is a personal, single-user utility. It is operated by one individual, reachable at lewis.rn.marshall@gmail.com, for their own Google account only. There are no other users, no customers, and no sign-up.

What data it accesses

Only Google Tasks data, and only for reading. The single permission requested is:

https://www.googleapis.com/auth/tasks.readonly

From that, the app reads the task lists and tasks on the operator's own account: each task's id, title, notes, due date and last-updated time.

It requests no other scope — no email content, no calendar, no contacts, no Drive files, no profile or identity information. Because the read-only Tasks permission carries no identity, the app does not learn the account's name or email address from Google at all; the operator types their own address into a local file so the tool can confirm it is running against the intended account.

What it does with that data

Task data is read into memory on the operator's own computer and printed there, for the operator's own assistant software to act on. That is the sole purpose.

What it stores

Stored locally on the operator's machine, in a private directory readable only by them:

  • an OAuth token, so the app does not have to ask for permission on every run;
  • the operator's own email address, as a local note of which account was authorised;
  • a list of task ids already processed, so the same task is not handled twice.

Nothing is stored anywhere else.

What it does not do

  • It does not send task data to any third party, server, or service.
  • It does not sell, rent, share, or trade data with anyone, for any purpose.
  • It does not use data for advertising, profiling, training, or analytics.
  • It does not modify, complete or delete anything in Google Tasks — it cannot; the permission it holds is read-only.
  • It has no other users, so there is no one else's data to handle.

Retention and deletion

Data lives only on the operator's machine and is deleted by deleting those local files. The operator can revoke the app's access to their Google account at any time at myaccount.google.com/permissions, after which the app can read nothing.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version replaces this page and the date above changes.
