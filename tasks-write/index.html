tasks-write

tasks-write is a small personal command-line tool that can mark the operator’s own Google Tasks as completed, fetch a task, and list task lists.

It is not a product, not a service, and not open for sign-ups. It runs on one machine, for one Google account, operated by the person who built it.

Separate from tasks-vizzy

tasks-write is a different app from tasks-vizzy. Vizzy only reads tasks (readonly poller). This tool can change task status. They use separate OAuth clients, separate tokens, and must not share a single Google grant.

What it does

  1. The operator runs a local CLI (python -m tasks_write …).
  2. With permission, it calls the Google Tasks API to complete or inspect tasks on that same account.
  3. Results are printed on the operator’s own machine for their own assistant software.

What it cannot do

  • It cannot act for anyone else. Credentials are for exactly one account, granted by that account’s owner, stored only on that owner’s machine.
  • It does not expand the vizzy poller’s scopes. Write access lives only in this app’s token.
