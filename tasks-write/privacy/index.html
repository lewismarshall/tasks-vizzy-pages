tasks-write — Privacy Policy

Last updated: 15 September 2026

tasks-write is a personal, single-user CLI. It is operated by one individual, reachable at lewis.rn.marshall@gmail.com, for their own Google account only. There are no other users, no customers, and no sign-up.

This policy applies only to tasks-write. It is not the privacy policy for tasks-vizzy (a separate readonly tool).

What data it accesses

Only Google Tasks data. The single permission requested is:

https://www.googleapis.com/auth/tasks

With that, the app can read and update tasks on the operator’s own account (for example marking a task completed). It requests no other scope — no email content, no calendar, no contacts, no Drive files.

What it does with that data

Task data is processed in memory on the operator’s own computer and printed there, for the operator’s own assistant software. That is the sole purpose.

What it stores

Stored locally on the operator’s machine, in a private directory readable only by them:

  • an OAuth token (write-scope), so the CLI does not have to ask for permission on every run;
  • the operator’s own email address, as a local note of which account was authorised.

Nothing is stored on the static HTTPS host used for OAuth branding and the auth-code bounce page. That host never receives access or refresh tokens — only a short-lived authorisation code that is immediately redirected to the local CLI.

What it does not do

  • It does not send task data to any third party, server, or service (beyond Google’s Tasks API).
  • It does not sell, rent, share, or trade data with anyone.
  • It does not use data for advertising, profiling, training, or analytics.
  • It does not share its token with tasks-vizzy or expand vizzy’s readonly grant.

Retention and deletion

Data lives only on the operator’s machine and is deleted by deleting those local files. The operator can revoke access at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
